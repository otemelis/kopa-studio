# POIS Growth metric dictionary

Checked 28 October 2026. Each metric retains its own source and grain. The first page defaults to **AU** for store/ad rows, while POIS client events are **all storefronts** because a reliable shared country dimension is not yet present in the bounded reader. Dates use UTC event time for POIS, source report dates for Apple, and labeled source currency. Production (`appstore`) and TestFlight are never combined. Only one app version is shown at a time.

| Metric | Numerator and denominator | Authority / status now | Date basis and limits |
| --- | --- | --- | --- |
| App Store impressions | Sum of ASC `Impression` counts; no denominator. | ASC Analytics; **unavailable** for POIS until rows arrive. | Report date and market; Apple thresholds/lag apply. |
| Product-page views | Sum of ASC `Page view` where page type is `Product page`; no denominator. | ASC Analytics; **unavailable**. | Report date/market; not Apple Ads taps. |
| First-time downloads | ASC first-time download measure if available; no denominator. | **Unavailable** in current POIS daily dataset. | Do not substitute Sales & Trends units. |
| Sales-report units | Sum of existing `aso_daily_metrics.downloads`; no denominator. | ASC Sales & Trends, **measured as units**; not first-time downloads. | Report date/market, with source/freshness. |
| First observed opens | Distinct installation IDs with `app_opened(first_launch=true)`; no denominator. | POIS 1.0/1.1 client event; **observed**, not Apple downloads. | Event UTC; consent, upload and reinstall limits. |
| Confirmed sensing | Distinct installation IDs with `airpods_state_changed(state='sensing')`; potential denominator is observed first opens in the same eligible cohort, not all downloads. | POIS client event; **observed**. | Event UTC; missing is not incompatible. First slice shows count without a cross-window conversion rate. |
| Onboarding completed | Distinct installation IDs with `onboarding_completed`; no implied denominator. | POIS client event; **observed**. | Event UTC and selected version/channel. |
| Proof heard | Distinct installation IDs with `proof_cue_actually_played`; no denominator. | POIS client event; **observed**. | Event UTC; `proof_started` is excluded. |
| Real session started | Distinct installation IDs with `session_started` and a session ID; no denominator. | POIS client event; **observed**. | Event UTC; demo events excluded. |
| Meaningful real session | Distinct installations with matched `session_started`/`session_ended` for the same session ID and `tracked_seconds >= 600` on the end; denominator is eligible real-session starters when a mature cohort definition is added. | POIS client event; **observed/partial** if recovery loses an ID or end is missing. | Evaluated seconds, not wall-clock seconds. A missing end remains unknown, never zero duration. |
| Real paywall viewer | Distinct installation IDs with `paywall_viewed(preview=false)`; no denominator in first slice. | POIS client event; **observed**. | Event UTC; trial eligibility is separate. |
| Client purchase completion | Distinct installation IDs with `purchase_completed`; no denominator. | POIS diagnostic only. | Never verified payment, trial or revenue. |
| Trial, first charge, active paid, renewal, cancellation, refund | Unique verified provider transaction/subscriber chains, with lifecycle-specific denominators. | **Unavailable**: POIS RevenueCat SDK key is nil, current webhook rows are sandbox only, subscription-state table is empty. | Requires verified production lifecycle, transaction dedupe and mature trial cohort. |
| Actual proceeds | ASC financial/Sales report proceeds with a known currency; no denominator. | **Unavailable for POIS** where currency is null or no settled report supports it. | Financial report period; do not infer from client events or count zero-currency rows as EUR 0. |
| Apple Ads impressions/taps/installs/spend | Sum of POIS-mapped official campaign report rows, same market, date basis and currency. CPI = spend / Apple Ads attributed installs only if denominator > 0. | **Unavailable in live POIS table**; supplied 21–27 Oct AU CSV is a historical reference, not imported daily data. | Apple Ads UTC report date; attributed installs differ from ASC downloads. |
| Meta delivery and paid CAC/ROAS | Provider-native report and defensible attribution join. | **Unavailable**. | No Meta feed; no ad-to-product or ad-to-revenue identity join. |
| D1/D7 and second-session-within-7d retention | Distinct eligible first-open or first-session cohorts with observed follow-up divided by matured cohort denominator. | **Unavailable in the first slice** pending verified session recovery and cohort maturity. | Define calendar-day vs rolling 7×24-hour retention separately. |

For all rows: a missing source or an incomplete/suppressed window is `null`/Unavailable, never zero; an observed zero is only valid after a successful complete source query. No small-sample percentage is presented without its counts, denominator, environment and version. Only the owner can access the page; raw event properties and identifiers remain server-side.
